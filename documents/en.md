## 🌟 Introduction

BitFlow Web is the Web branch version of [BitFlow](https://github.com/Zhoucheng133/BitFlow). It aims to provide a clean, responsive, and powerful download manager frontend that connects and manages multiple mainstream download engines.

## ✨ Key Features

- **Multi-downloader Support**: Fully supports **qBittorrent**, **Aria2**, and **Transmission**.
- **Responsive Multi-platform Design**: Finely tuned and optimized UI for both Desktop and Mobile devices.
- **PWA Support**: Can be installed as a Progressive Web App on desktop or mobile home screens for a native app-like experience.
- **Internationalization (i18n)**: Built-in support for Simplified Chinese, Traditional Chinese, English, Japanese, Korean, Russian, French, German, Spanish, Portuguese, and more.
- **Themes & Appearance**: Supports light/dark mode toggling and customizable themes.
- **Modern UI**: Powered by Flutter Material Design with a clean, fluid interface and efficient interactions.

## 📦 Deployment Guide

You can deploy the static files generated by `flutter build web` to any static hosting service (such as GitHub Pages, Cloudflare Pages, Vercel, Nginx, etc.).

> [!IMPORTANT]
> **CORS & qBittorrent Notes:**
> - **qBittorrent** does not support direct cross-origin Web API access by default. When connecting the Web version to a self-hosted qBittorrent instance, you typically need to set up a **reverse proxy** (such as Nginx or Caddy) to handle CORS headers and proxy the API requests.
> - **Aria2** and **Transmission** generally work out of the box with proper RPC credentials and CORS settings enabled (e.g., Aria2's `--rpc-allow-origin-all`), avoiding most CORS issues.

## 🛠️ Local Development & Building

If you want to run development locally or build it yourself:

1. **Prerequisites**
   Make sure you have Flutter installed (recommended version **`3.41.6`** or compatible Flutter 3.x), see [Flutter Installation Guide](https://docs.flutter.dev/get-started/install).

2. **Clone & Install Dependencies**
   ```bash
   git clone https://github.com/Zhoucheng133/BitFlow-Web.git
   cd BitFlow-Web
   flutter pub get
   ```

3. **Run Locally for Debugging**
   ```bash
   flutter run -d chrome
   ```

4. **Build for Production**
   ```bash
   flutter build web
   ```
   If deploying to a subpath (e.g., GitHub Pages `/BitFlow-Web/`), specify `--base-href`:
   ```bash
   flutter build web --base-href /BitFlow-Web/
   ```
